Flow: GitHub → Infra

Sock Shop lab · protected main · images via ECR · catalogue DB via Flyway/RDS · app runs on EC2

Git / PR GitHub Actions ECR (images) Flyway (DB) EC2 runtime RDS MySQL

How it runs

  1. Code — create a branch, open a PR into main (no direct push).
  2. 2. Pre-merge — lint/build green → merge (or lab bypass).
  3. 3. Release — Conventional Commits on main → tag <service>-vX.Y.Z.
  4. 4–6. Promote image — manual: build the service → push ECR env-1 / env-2 / env-3. Does not run Flyway.
  5. 7. Migrate catalogue DB — manual, separate workflow: Flyway info then migrate on RDS socksdb (new RDS or new schema).
  6. EC2 — pull images from ECR, docker compose up; catalogue uses the RDS DSN; Mongo/Rabbit on the same EC2.
